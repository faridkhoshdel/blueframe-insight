# 🚀 blueFrame Insight

پلتفرم هوشمند مدیریت کسب‌وکار با AI

## ویژگی‌ها
- 🧠 Explainable AI Lead Scoring
- 🕸️ Knowledge Graph Visualization
- 🧪 Digital Twin Simulator
- 🤖 Autonomous Agents
- 🎙️ Multimodal AI (Voice, Image, Text)
- 📊 Executive Dashboard

## Tech Stack
- **Frontend**: Next.js 14, TypeScript, Tailwind CSS, Recharts
- **Backend**: NestJS, Prisma, PostgreSQL
- **AI**: Groq API (Whisper, Llama Vision)
